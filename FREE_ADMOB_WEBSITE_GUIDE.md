## 🚀 Option 2: GitHub Pages (100% Free Forever, Custom Domain & High Availability)

The `/docs` directory in this project is pre-configured for GitHub Pages.

1. **Create/Open your GitHub Repository:**
   * If you create a repository named `<your-username>.github.io` (for example, `niharbhuyan.github.io`), GitHub serves it directly at the root domain!
2. **Push the project code to GitHub.**
3. **Enable GitHub Pages:**
   * Go to your repo on GitHub &rarr; **Settings** &rarr; **Pages** (in the left sidebar).
   * Under **Build and deployment**:
     * Source: `Deploy from a branch`
     * Branch: `main` (or `master`)
     * Folder: `/docs` (or `/root`)
   * Click **Save**.
4. Within 1 minute, GitHub creates your free website:
   * **Website:** `https://<your-username>.github.io/`
   * **app-ads.txt:** `https://<your-username>.github.io/app-ads.txt`
5. In **Google Play Console**, enter `https://<your-username>.github.io/` as your Developer Website!
